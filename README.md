# Sports Analytics Case Studies

**Three data analytics projects from the Applied Data Analytics in Sports Management course at FSU.**

Each case study uses a different method — regression, logistic modeling, and clustering — applied to real sports datasets.

---

## Projects

### [Case Study 1 — Dodgers Stadium Attendance Analysis](./Case%20Study%201)]
Regression model predicting percent capacity at Dodgers Stadium from 2014–2022. Examines how opponent, month, team performance, and game-day variables drive attendance. Best model explained ~22% of variance in percent capacity.

### [Case Study 2 — Expected Goals (xG) Model, Women's Soccer](./Case%20Study%202)]
Logistic regression model predicting shot conversion probability in the 2018 NWSL season. Uses shot location, goalkeeper position, and defensive pressure to build an xG model, then evaluates individual player and team finishing performance against expectations.

### [Case Study 3 — NFL Wide Receiver Clustering](./Case%20Study%203)]
K-means clustering model grouping historical NFL wide receivers into five archetypes by performance profile, then mapping 2024 draft prospects onto those clusters to identify comparable players already in the league.
